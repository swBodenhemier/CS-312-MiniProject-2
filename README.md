# API App

This site provides weather information for a specific street address.

## APIs

https://goecode.maps.co Translate between street address and longitude latitude.

https://api.openweathermap.org Get weather information at specific longitude latitude,

## Usage

In order to use this App you must have API keys for both of the above API's.

Once you have the keys, you can create a secrets.js file and export them as constants named geocodeKey and openWeatherKey respectively.

`export const geocodeKey = "1234abcd"` \
`export const openWeatherKey = "abcd1234"`
